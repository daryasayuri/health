## Текущие жалобы

### Кожа
- Зуд лица (лоб, скулы) с покраснением после еды
- Усиливается к вечеру
- Провоцируется едой (накопительный эффект в течение дня)
- Ранее: сильный зуд ног на фоне приёма Визанны и КОКов → отменила

### ЖКТ
- Непереносимость жирной пищи: боль, несварение
- Непереносимость жареных яиц (особенно утром)
- Ранее: императивные позывы после еды (сейчас купированы диетой)

### Энергия и общее самочувствие
- Усталость к 15:00, общая разбитость
- Часто болеет (сниженный иммунитет)
- Силы восстанавливаются после сна, но не полностью

### Цикл
- Сейчас регулярный (после отмены гормонов)
- Эндометриоз в анамнезе ассоциирован с болезненными/обильными менструациями (уточнить)

## Ключевые гипотезы

### 1. Эстроген-гистаминовый цикл

```
Эндометриоз
     ↓
Избыток эстрогена
     ↓
Стимуляция тучных клеток → выброс гистамина
     ↓
Зуд кожи / покраснения / кишечные симптомы / тревожность
     ↓
Гистамин стимулирует яичники → ещё больше эстрогена
     (порочный круг)
```

**Почему зуд на гормонах был особенно сильным:** экзогенный эстроген (КОКи, Визанна) → резкий рост гистамина → выраженный зуд.

### 2. Дисфункция сфинктера Одди (а не дефицит желчи)

Ключевое наблюдение: **Урсосан и Хофитол усиливали боль** — оба увеличивают объём желчи. Если бы проблема была в нехватке желчи, они бы помогли. Значит желчи достаточно, но отток нарушен.

```
Сфинктер Одди спазмирован / открывается нерегулярно
     ↓
Желчь давит на протоки → боль в правом подреберье
     ↓
Урсосан/Хофитол добавляют объём → давление растёт → боль усиливается
     ↓
Желчь поступает в кишечник нерегулярно
     ↓
Жиры не расщепляются (жирные кислоты в копрограмме ++)
     ↓
Нарушение всасывания железа + жирорастворимых витаминов
     ↓
Падение ферритина → усталость, частые болезни
```

**Вывод:** нужны не желчегонные, а спазмолитики. Стимулировать желчь при спазме сфинктера = подливать воду в засорённую трубу.

## Диета (работающие ограничения)

**Исключено / плохо переносится:**
- Жареные яйца (особенно утром)
- Жирные блюда (жирные супы, жирное мясо)
- Жирное в целом → боль и несварение

**Что улучшило состояние:**
- Ограничение жиров
- Исключение жареных яиц по утрам
- Нет яиц утром → нормализация стула

## Добавки — вздутие/ЖКТ (август 2026)

**Симптом:** физическое вздутие/отёчность живота (не просто газообразование). Два компонента:
- Циклический — привязан к периоду перед/во время месячных → укладывается в гипотезу эстроген-гистаминового цикла
- Постоянный фон — без чёткой закономерности → возможная связь с нерегулярным оттоком желчи (гипотеза по сфинктеру Одди): желчь обладает антибактериальным действием, при нерегулярном поступлении растёт риск избыточного бактериального роста (СИБР)

**Рекомендация:** добавить дыхательный тест на СИБР в Волну 2 (вместе с УЗИ с желчегонным завтраком).

### Избегать — та же категория риска, что Урсосан/Хофитол

Стимулируют желчь/жёлчный, при спазме сфинктера Одди могут усиливать боль так же, как отменённые препараты:
- Лецитин
- Куркумин/турмерик (холагог)
- Артишок в любом виде (не только Хофитол)
- "Liver detox" / "bile support" добавки, одуванчик

## Следующие шаги (приоритет)

1. **Витамин D — начать немедленно** (не ждать остальных анализов). Уровень 11.91 — выраженный дефицит. Стандартно: 4000–5000 МЕ в день, принимать с жирной едой (жирорастворимый). Контроль через 3 месяца. Обсудить дозу с врачом.

2. **Фолиевая кислота** — добавить 400–800 мкг в день или увеличить листовую зелень в рационе (шпинат, брокколи, петрушка). Нужна для кроветворения — поможет ретикулоцитам.

3. **Дождаться остальных анализов** (железо, трансферрин, sTfR, цинк) — тогда будет полная картина по железу и можно решать нужно ли его дополнительно принимать.

4. **Гистаминовая диета 2–4 недели** — исключить высокогистаминовые продукты (выдержанные сыры, уксус, копчёности, консервы, томаты) и оценить изменение зуда.

5. **Сфинктер Одди** — УЗИ с желчегонным завтраком + консультация гастроэнтеролога. Не желчегонные (Урсосан, Хофитол — противопоказаны), а спазмолитики.

6. **Гинеколог** — контроль эндометриомы, обсуждение нехормональных подходов при эндометриозе.
